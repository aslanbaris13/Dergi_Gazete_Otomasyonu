## Overview

A fully functional desktop application for managing a magazine and newspaper distributor's subscriptions, inventory, and reporting — built with C# Windows Forms and MS SQL Server.

> 🗂️ **Archived academic project.**

---

## Features

- 📰 **Publication Management** — Register and track magazines and newspapers with stock and pricing
- 👥 **Subscriber Module** — Manage subscription start/end dates and payment status
- 📊 **Dynamic Reporting** — Sales data and publication statistics
- 🗄️ **SQL Features** — Custom queries, stored procedures, triggers, and INNER JOINs
- 🏗️ **N-Tier Architecture** — Separated Business Logic, Data Access, and UI layers

## Setup

```bash
git clone https://github.com/aslanbaris13/Dergi_Gazete_Otomasyonu.git
```
1. Open `Dergi_Gazete_Otomasyonu.sln` in Visual Studio
2. Update the connection string for your local SQL Server
3. Restore NuGet packages and build (F6)
4. Run (F5)
